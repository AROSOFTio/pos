# MauzoPOS public brand assets

Place the system-level brand files here:

- mauzopos-logo-light.png — horizontal logo for light backgrounds
- mauzopos-logo-dark.png — horizontal logo for dark backgrounds
- mauzopos-icon.png — square 512×512 PNG app/PWA icon
- hero.webp — homepage hero artwork

Customer/business logos are uploaded from Settings → Business / Branding and are stored in /uploads/branding/. Do not place tenant logos in this folder.

All PNG brand assets are optional. The React UI has a built-in vector fallback if a file is absent.
